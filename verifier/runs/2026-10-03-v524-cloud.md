### Limites constatées

Le téléchargement standard de Chromium a échoué. Un Chromium 153 empaqueté a permis la vérification, avec rendu 2D : ces résultats ne certifient pas les performances GPU ou Safari sur iPhone.

La vérification de performance des phénomènes échoue pour la faille temporelle (21,247 ms mesurées contre un plafond de 2 ms). La suite des routes a vérifié les bifurcations, le choix tactile et la reprise, mais n’a pas pu être certifiée intégralement : fermeture du navigateur avec le profil à processus unique, puis écart de cadence mesuré sur la Forge dans un autre profil. La suite générale run.cjs n’a pas terminé avec un résultat global exploitable. Les sept échecs attendus annoncés par le relais de Claude n’ont donc pas été reconfirmés comme seule liste d’échecs.

Les premiers essais en rendu logiciel GPU ont aussi produit des échecs liés au rythme des scènes. Le retour en 2D a permis de faire passer smoke13 et photo17 ; cela indique une dépendance au profil d’exécution, sans prouver que tous les autres échecs ont la même cause.

Il reste à essayer la fluidité, les gestes et le mixage sur un iPhone réel. Le classement et le tournoi dépendent du service Supabase existant ; leur disponibilité n’est pas garantie par cette publication.

## Commandes de reprise

```sh
npm ci --ignore-scripts
npm run build
npm test
python3 tools/build-cloud.py
npm install --no-save playwright
npx playwright install chromium
node tests/cloud-smoke.cjs
node tools/serve-cloud.cjs dist 8179
```

Le serveur prend en charge Range pour la lecture MP3. Le test cloud démarre son propre serveur, effectue les contrôles et ferme ses processus. Une capture temporaire peut être demandée en argument.

Pour republier, réutiliser le même projet Sites, identifié par `appgprj_6ac0b563af5c8191a2c6a7c08112432f`, après ouverture de ses sources et intégration du nouveau commit GitHub. Le dépôt GitHub reste la source de référence. Vérifier le distant et lire AGENTS.md avant chaque reprise ; ne pas repartir de main.

Les sauvegardes du jeu sont locales à l’adresse et au navigateur. Une progression sur l’Artifact Claude ou une autre adresse n’est pas automatiquement transférée. Cette livraison constitue une version manuellement publiée ; elle n’installe pas de développement permanent ou d’automatisation.
